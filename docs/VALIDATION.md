## 发布检查
公开版本只包含源代码、测试、文档、许可证、数据来源元数据和脱敏实验记录。权重、下载语料、缓存、机器日志及密钥文件排除在Git之外。

首次克隆流程检查发现并修复了两点：验收脚本需自行创建被忽略的日志目录；下载器不得在重新下载时沿用旧来源文件的下载时间。后者新增回归测试，已先执行失败基线。

原始环境的NumPy2.4.0被上游以兼容性问题撤回；发布版本使用未撤回的NumPy2.4.6。在项目忽略目录内隔离安装该版本，原全局环境不变；只含暂存文件的干净导出目录中执行测试，结果为 **17 passed, 1 skipped**（18.53秒）。新增数据来源时间戳回归测试通过。

## 验证边界
CPU原始实验、配对初始化、数据隔离、因果性和生成接口均有实测依据。不宣称GPU/MPS、所有Python版本、所有操作系统或跨硬件位级复现成功。验证集是固定抽样窗口并用于best checkpoint选择，没有独立测试集。

公开文件中的环境路径已改为相对路径或移除；每次自行运行仍会在本地保存真实完整元数据。完整本地开发证据不上传，以避免暴露机器用户名、路径和服务进程信息。


依赖解析采用 `pip install --dry-run --ignore-installed --only-binary=:all: -r requirements.txt`，在公开PyPI解析60个包成功，未选择被撤回版本。直接依赖已固定；这是依赖解析验证，并不等于完整新虚拟环境安装。本轮测试复用原有其他依赖，NumPy使用隔离修复版。
