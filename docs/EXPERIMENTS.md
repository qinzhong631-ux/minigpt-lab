# 单头与四头：受控教学实验

## 问题和预先设定的指标
在总模型宽度、参数量、语料与优化更新预算一致时，改变 head 数会怎样影响短程字符语言模型的验证损失？主要指标为第 200 步固定抽样验证窗口的平均交叉熵（nats/字符，越低越好）。不把两组不同时刻的 best loss 作为主比较指标。

## 设计
- 1 vs 4 heads；宽度 64、层数 2、FFN 宽度 256、上下文 64、batch 8。
- 三个配对种子 42/43/44。每对初始化参数的 SHA256 一致，见各运行 metadata.json。
- AdamW，lr=0.0003，weight_decay=0.01，梯度裁剪=1，dropout=0，CPU 两线程。
- 相同原始文本/切分/词表；训练批次种子为 seed+10；评估训练/验证批次种子为 seed+1000 / seed+1001。
- 每组200步，所有步骤均保存当前批次损失；每50步和第0步用10个batch评估。
- 同种子两组评估窗口相同，种子间窗口不同；因此跨种子标准差包含初始化/训练抽样及评估抽样变化。
- 运行顺序固定为每个种子先单头后四头。耗时只作记录，不是严格速度基准。

## 为什么参数量能完全一致
注意力用一个 d→3d 的 QKV 投影和一个 d→d 输出投影。包含 bias 时总参数为 4d²+4d，与 head 数 H 无关。H 只影响 reshape 与每头维度 d/H。

每层包含两个 LayerNorm（4d）、注意力（4d²+4d）、FFN（8d²+5d），共 12d²+13d。加上独立输入/输出词嵌入 2Vd、位置嵌入 Td、最终归一化 2d，总参数：

`2Vd + Td + L(12d² + 13d) + 2d = 113920`（V=76, d=64, T=64, L=2）。未共享输入输出权重。

## 解释和局限
本次单头数值略低，差异不足以支持一般性结论。这里只运行一个语料、三个种子、很小的模型与很短的更新预算，没有显著性检验，也没有独立测试集。

等参数不代表完全等计算：单头每头维度64，四头每头维度16，softmax 的矩阵数量、缩放因子、表示结构和中间激活显存都变化。投影主项 FLOPs 接近，但实际算子调度和耗时可以不同。本实现显式构造注意力矩阵，矩阵存储随 H 增加；不能把比较解释为仅改变一个无成本标签。

本次 dropout=0，使配对随机性容易控制；将来启用 dropout 后，注意力张量形状不同会改变随机掩码，不能仅凭同 seed 宣称所有随机操作对应。PyTorch 确定性开关不保证跨库版本/设备逐位相同。

可扩展方向：预先固定更多种子与独立评估窗口、增加训练预算及多语料、另留测试集、测量峰值内存与同步设备耗时。未实际运行这些扩展。
