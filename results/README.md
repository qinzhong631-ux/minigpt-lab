# 实测结果 / Measured results

本目录保留2026-10-12实际CPU实验的CSV损失曲线、JSON配置/摘要、词表及未经润色的生成样本。数据来自本地 runs/，导出时仅去除解释器绝对路径、将数据/输出目录改为相对路径；loss、随机种子、初始化/语料校验值与耗时未改动。

- default/：4头、seed42、1000步展示训练。
- smoke/：10步CPU流程检查。
- comparison/：1/4头 × seed42/43/44，每组200步；包含全部配对记录与均值/样本标准差。

不提供预训练权重；权重与新训练输出写入被Git忽略的 runs/。克隆后请按照README准备数据并训练。metadata中的源文件SHA256描述实验发生时的源码，而不是对后来文档/发布工具变更的声明。

详细方法见 [实验报告](../docs/EXPERIMENTS.md)。单次短训练和三个种子不足以支持普遍性结论。
